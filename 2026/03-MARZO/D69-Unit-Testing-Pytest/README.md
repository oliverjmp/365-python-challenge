# Módulo D69: Unit Testing & Coverage

Este módulo implementa un transformador ETL (`ETLTransformer`) robusto con validación de esquemas mediante Pydantic y una suite de pruebas unitarias exhaustiva con `pytest`.

## Características
- **ETL Robusto:** Validación estricta de tipos y limpieza de datos.
- **Unit Testing:** Cobertura de escenarios exitosos, casos nulos y datos corruptos.
- **Calidad de código:** Automatización de pruebas y reporte de cobertura.
