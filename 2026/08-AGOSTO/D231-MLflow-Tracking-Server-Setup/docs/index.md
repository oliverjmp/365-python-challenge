# D231 - MLflow Tracking Server Setup: Especificación Técnica y Arquitectura

## 🏢 Resumen Ejecutivo y Alcance
El hito **D231** introduce el bloque de MLOps mediante la configuración de un servidor de trazabilidad de experimentos con MLflow y almacenamiento SQLite. Su propósito es garantizar la reproducibilidad y el control cuantitativo de los modelos predictivos en desarrollo.

### Objetivos Clave
* **Registro Automatizado:** Captura de parámetros y métricas de modelos de manera estructurada.
* **Persistencia Robusta:** Almacenamiento local desacoplado utilizando bases de datos relacionales ligeras.
