# D165 - Geospatial Mapping con Folium y Streamlit

Creación de mapas interactivos georreferenciados para la visualización de ubicaciones de negocio, marcadores personalizados y análisis de densidad de operaciones.

## Características Principales
- **Integración Folium + Streamlit:** Renderizado fluido de mapas HTML interactivos dentro de aplicaciones analíticas web.
- **Marcadores Personalizados:** Inserción dinámica de puntos de interés con popups informativos y metadatos asociados.
- **Pruebas Unitarias Automatizadas:** Validación lógica de la construcción de mapas y estructuras de coordenadas.
