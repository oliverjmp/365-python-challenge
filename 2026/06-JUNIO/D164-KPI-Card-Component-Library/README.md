# D164 - KPI Card Component Library

Desarrollo de componentes de interfaz de usuario reutilizables y modulares en `Streamlit` para la visualización elegante y estandarizada de Indicadores de Rendimiento Clave (KPIs).

## Características Principales
- **Componentes Modulares:** Funciones encapsuladas para renderizar tarjetas de métricas personalizadas con soporte para tendencias, variaciones porcentuales y estilos visuales limpios.
- **Reutilización de UI:** Diseñado para mantener consistencia visual en dashboards corporativos y analíticos.
- **Validación y Pruebas:** Cobertura de pruebas unitarias para garantizar el correcto formateo y estructuración de los datos mostrados en los componentes.
